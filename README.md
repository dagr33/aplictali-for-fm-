# FM Application

A simple and modern FM application built with Node.js.

## Features

- Clean and modern web interface
- Lightweight and fast
- Easy to run and deploy

## Prerequisites

- Node.js (version 12 or higher)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/dagr33/aplictali-for-fm-.git
cd aplictali-for-fm-
```

2. No additional dependencies needed - uses Node.js built-in modules!

## Usage

Start the application:

```bash
npm start
```

The application will be available at `http://localhost:3000`
